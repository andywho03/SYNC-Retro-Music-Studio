SYNC - Retro Music Studio
---

English

**SYNC** is a desktop music player and audio downloader with a nostalgic retro aesthetic inspired by classic P2P software (like Ares) and modern streaming platforms. 

This project was born as a **UI/UX design and creative coding practice**. As a Graphic Designer exploring product design, I created the entire visual concept, color palette, and user flow from scratch in **Figma** and brought it to life as a working Windows desktop application.

###  Design & Features
* **Custom UI/UX System:** Handcrafted retro-modern interface built around a warm custom palette (*Merino* `#F5EEDD`, *Rock Blue* `#84B3CE`, and *Venice Blue* `#16587B`).
* **Smart Search Dropdown:** Search by artist or song name to preview top results and durations before downloading, or paste direct links.
* **Live Audio Visualizer:** Dynamic 15-bar soundwave animation synced with real-time playback.
* **Local Music Library:** Automatically scans downloaded MP3s, retrieves album covers, and displays file size and track duration.
* **Integrated Media Player:** Full playback controls including play/pause, next/previous track, shuffle, repeat mode, and live progress tracking.

###  Tech Stack & Tools Used
* **UI/UX Design:** Figma
* **Language:** Python 3
* **GUI Framework:** CustomTkinter & Pillow (PIL)
* **Audio & Metadata Engines:** `yt-dlp`, `FFmpeg`, `requests`, and Windows native `winmm` (MCI)
* **Packaging:** PyInstaller

###  How to Download & Run (Windows)
1. Go to the **Releases** section on the right side of this repository.
2. Download the latest `SYNC_Retro_Studio.zip` file and extract it.
3. Double-click `SYNC_Retro_Studio.exe` to launch the app (no Python installation required).

##  Español

**SYNC** es un reproductor de música y gestor de descargas para escritorio con una estética retro nostálgica inspirada en los programas clásicos (como Ares) y las interfaces actuales de streaming.

Este proyecto nació como una **práctica de diseño UI/UX y desarrollo creativo**. Como Diseñadora Gráfica enfocada en el diseño de productos digitales, diseñé toda la identidad visual, la paleta de colores y la experiencia de usuario desde cero en **Figma** y la llevé a una aplicación funcional para Windows.

###  Diseño y Características
* **Sistema Visual Personalizado (UI/UX):** Interfaz retro-moderna diseñada con una paleta cálida (*Merino* `#F5EEDD`, *Rock Blue* `#84B3CE` y *Venice Blue* `#16587B`).
* **Buscador Desplegable Inteligente:** Busca por nombre de artista o canción para previsualizar resultados y duraciones antes de descargar, o pega enlaces directos.
* **Visualizador de Audio en Vivo:** Onda de sonido animada de 15 barras sincronizada con la reproducción.
* **Biblioteca Local Automática:** Escanea los archivos MP3 descargados, recupera sus carátulas de álbum y muestra el peso en MB y la duración exacta.
* **Reproductor Integrado:** Controles multimedia completos con reproducción, pausa, pista anterior/siguiente, modo aleatorio, repetición y barra de progreso en tiempo real.

### Tecnologías y Herramientas Utilizadas
* **Diseño UI/UX:** Figma
* **Lenguaje:** Python 3
* **Interfaz Gráfica:** CustomTkinter y Pillow (PIL)
* **Motores de Audio y Descarga:** `yt-dlp`, `FFmpeg`, `requests` y la librería nativa de audio de Windows (`winmm`)
* **Empaquetado:** PyInstaller

### Cómo Descargar y Usar (Windows)
1. Ve a la sección **Releases** (Lanzamientos) en el menú derecho de este repositorio.
2. Descarga el archivo `SYNC_Retro_Studio.zip` y descomprímelo.
3. Abre `SYNC_Retro_Studio.exe` con doble clic (no necesitas instalar Python ni configuraciones extra).
